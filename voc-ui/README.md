# VOC UI 초안

`dist/index.html`을 브라우저로 열면 됩니다. HTML, CSS, JavaScript만 사용하며 설치 과정은 없습니다.

- 샘플 민원 6건 선택·검색·상태 필터
- 원문, 요지, 키워드, 발생 원인 표시
- 추출 위치, 관할본부, 업무기능, routing_scope 표시
- 추천부서 1·2순위, 점수, 근거 건수 표시
- 부서 선택과 승인·보류, 이 브라우저에서의 상태 저장

실제 Excel, Qwen, 노트북, 부서 전달 시스템과 연결되지 않은 UI 초안입니다. 부서명·점수·근거는 화면 확인용 예시입니다. 일부 2순위는 보조 기능 후보를 표시한 예시이며 실제 노트북의 필터 결과를 재현하지 않습니다.

후속 연동 시 `app.js`의 samples를 분석 결과/API 응답으로 바꾸고 saveDecision을 승인 저장 API에 연결하면 됩니다.
